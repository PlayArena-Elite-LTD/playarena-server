# Day 29 - User Acceptance Testing (UAT)

Goal: Validate the full user journey with test accounts and gather feedback.

## 1) UAT Preparation
- [ ] Create UAT test accounts (player, staff, admin)
- [ ] Prepare test data (wallet balance, matches, disputes)
- [ ] Create UAT script and checklist for testers
- [ ] Set up feedback collection channel

## 2) Full User Journey
- [ ] Sign up as new user
- [ ] Verify email confirmation (if enabled)
- [ ] Login and edit profile
- [ ] Deposit funds successfully
- [ ] Create a match
- [ ] Join a match as another user
- [ ] Submit match results
- [ ] Upload evidence files
- [ ] Withdraw funds

## 3) Dispute & Support Flow
- [ ] Trigger dispute from mismatched results
- [ ] Support staff reviews evidence
- [ ] Support staff resolves dispute
- [ ] Confirm wallet balances updated correctly

## 4) Messaging & Notifications
- [ ] Send messages between users
- [ ] Confirm unread badge updates
- [ ] Notifications delivered correctly (if used)

## 5) Admin Workflow
- [ ] Admin reviews deposits/withdrawals
- [ ] Admin reconciles wallets
- [ ] Admin reviews audit logs

## 6) Feedback & Fixes
- [ ] Collect tester feedback
- [ ] Log all reported bugs
- [ ] Prioritize critical fixes
- [ ] Retest critical fixes
