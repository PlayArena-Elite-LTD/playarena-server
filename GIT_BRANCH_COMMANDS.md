# Git Branch Commands

## Check Branches

### List all local branches:
```powershell
git branch
```

### List all branches (local and remote):
```powershell
git branch -a
```

### List only remote branches:
```powershell
git branch -r
```

### Show current branch with more details:
```powershell
git branch -v
```

### Show current branch with last commit:
```powershell
git branch -vv
```

## Most Common Command:
```powershell
git branch
```
This shows all local branches with an asterisk (*) next to the current branch.
